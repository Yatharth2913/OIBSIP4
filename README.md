# Email Spam Detection Using Machine Learning

## Project Overview
This project uses Machine Learning and Natural Language Processing (NLP) to detect whether an email/message is spam or not spam.

The model is trained on a spam message dataset and classifies messages into:
- Spam
- Ham (Not Spam)

---

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

---

## Features
- Text preprocessing
- Spam message classification
- Machine learning model training
- Accuracy evaluation
- Confusion matrix visualization
- Sample spam prediction

---

## Dataset
SMS Spam Collection Dataset

---

- Multinomial Naive Bayes
